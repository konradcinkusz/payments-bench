# Plans

One plan file per stream of work. Each lists its slices, the branch and pull request for each, its
acceptance criteria, and a findings section for what the work caught.

- `stream-a-core.md`: core and correctness.
- `stream-b-platform.md`: platform, delivery, identity.
- `stream-c-docs.md`: documentation, overview, PDF, site.

A plan describes intended work. Until a slice has merged, the documents describing the system
([`../OVERVIEW.md`](../OVERVIEW.md), the README, the site and the PDF) do not describe it as done.
